Design System / from reference
● Visual language

A soft, friendly,
modern product system.

Airy whitespace, white cards floating on a faint cool-gray canvas, a calm sage green leading, and a family of pastel accents for warmth. Generous rounding throughout. Built to feel polished, friendly, and approachable.

Color

Neutrals carry the layout; the sage green is the single brand voice; the pastels are how categories, avatars, and moods get their personality. Use soft tints for backgrounds and the solid version for the icon or detail sitting on top.

Using this in the build

Every value above is a CSS variable in the :root block at the top of this file. Copy that block into the Make Me Laugh app and the look comes with it. The quick rules:

  • White --surface cards on the --bg canvas, never color on color.
  • One --brand sage for the main action. Everything else stays neutral or pastel.
  • Each humor style gets its own pastel: soft tint as the chip, solid as the icon.
  • Pills for buttons, 20px corners for cards, soft shadows only. No hard edges, no heavy borders.
  • Build hierarchy with weight and space before reaching for size or color.
